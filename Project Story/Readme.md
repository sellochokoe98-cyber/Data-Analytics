# Diabetes Data Analysis Project

## 🧠 Problem
I worked with a healthcare dataset to understand patterns related to diabetes and patient health.

## 🛠 Tools Used
- SQLite
- Excel
- Python (Pandas)
- Power BI

## ⚙️ What I Did
- Cleaned the dataset
- Changed values (0/1 → Yes/No)
- Removed missing data
- Wrote SQL queries for analysis
- Created visual insights

## 📊 Key Findings
- Higher diabetes risk in older age groups
- Clear patterns between lifestyle and health indicators
- Data quality issues were identified and cleaned

## 🎯 Conclusion
This project shows how data can be used to support healthcare decisions and improve insights.
